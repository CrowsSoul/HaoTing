# M2 智能安规检查（自研算法）

**负责人**：宋馨雨　　**目录**：`nxdrp/checkers/m2_safety/`

## 这个模块在解决什么

连接器里两个带电部件离得太近，电压高的时候会击穿空气打火。
要自己算出所有导体配对之间的最短距离（电气间隙），以及沿绝缘表面走的最短路径（爬电距离），对照 IEC 60664-1 的限值判定。另外装一个 AutoCrear，用它算出来的结果给自研算法做对照。

## 你负责的检查项

| ID | 名称 | 难度 | 期次 | 判定要点 |
|---|---|---|---|---|
| `SAF-01` | 电气间隙 | L2 | 一期 | 导体两两配对求最短空间直线距离，与 IEC 60664-1 限值比对；AutoCrear 结果作对照 |
| `SAF-02` | 爬电距离 | L3 | 一期 | 沿绝缘表面求最短泄漏路径，处理沟槽/筋/倒角规则；AutoCrear 结果作对照 |
| `SAF-03` | 安规不合规归集 | L1 | 一期 | 综合间隙与爬电结果，任一项低于限值即判不合规并分级 |
| `SAF-04` | 安规量化建议 | L2 | 二期 | 输出目标尺寸：增大间隙到 X mm / 增加绝缘筋使爬电达到 Y mm |

## 从哪开始

先做 SAF-01 电气间隙——本质是两点距离，几何上有标准解法，把链路打通。
再攻 SAF-02 爬电距离——沿绝缘件曲面找最短路，这是全项目唯一需要科研攻关的地方。
同时把 AutoCrear 装起来，能独立跑出一次爬电结果，后面拿它当基准。

## 三个命令

```powershell
python -m nxdrp checkers                                   # 确认自己被认出来了
python -m nxdrp check mockdata/models/board_a.model.json --only <你的ID>
python -m unittest discover -s tests
```

## 几个提醒

- IEC 限值表放 `rules/`，每条注明标准表号，不要写进代码。
- AutoCrear 装好之后，先拿同一个模型跑一遍，把它的结果存下来当对照样例。
- 爬电距离第 5 周（按两周节奏就是第 5 天）必须有一个能跑的 v0.1，跑不出来就启动降级方案。
