# M6A 钣金类 DFM（8 项）

**负责人**：于大淇　　**目录**：`nxdrp/checkers/m6a_sheet_metal/`

## 这个模块在解决什么

钣金件折弯会裂、冲孔离板边太近会撕裂、翻边太高会拉断。
这 8 项就是在出图之前，把「做不出来或者做出来很贵」的地方标出来。

## 你负责的检查项

| ID | 名称 | 难度 | 期次 | 判定要点 |
|---|---|---|---|---|
| `DFM-19` | 最小弯曲半径 | L1 | 一期 | 内 R/料厚 t < 材料下限（冷轧钢 0.5~1.0） |
| `DFM-20` | 孔到边缘距离 | L1 | 一期 | 孔边到板边距离 < 1.5t~2t |
| `DFM-21` | 孔间距 | L1 | 一期 | 相邻孔净距 < 2t |
| `DFM-22` | 孔径与料厚比 | L1 | 一期 | 冲孔直径 < 料厚 |
| `DFM-23` | 槽的最小宽度 | L1 | 一期 | 槽宽 < 1.2t |
| `DFM-24` | 折弯与切口距离 | L2 | 二期 | 切口/孔到折弯线距离 < 3t + R |
| `DFM-25` | 翻边高度 | L1 | 一期 | 翻边高 < 3t + R（否则边缘撕裂） |
| `DFM-26` | 冲压凸台高度 | L1 | 二期 | 凸台高/t 超出允许区间 |

## 从哪开始

这 8 项几乎都是同一个套路：量一个尺寸，除以料厚，跟经验比值比。
先搭一套读表执行的代码，再把 8 行阈值填进去。

## 三个命令

```powershell
python -m nxdrp checkers                                   # 确认自己被认出来了
python -m nxdrp check mockdata/models/board_a.model.json --only <你的ID>
python -m unittest discover -s tests
```

## 几个提醒

- 料厚从 `ModelBundle.parts[].bbox` 或零件属性里取，取不到就声明 `requires` 并跳过。
- 标准比值放 `rules/dfm_default.json` 的 DFM-19~26 段，不要写死在代码里。
