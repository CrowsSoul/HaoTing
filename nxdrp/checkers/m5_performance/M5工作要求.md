# M5 智能性能预测

**负责人**：杜滨芳　　**目录**：`nxdrp/checkers/m5_performance/`

## 这个模块在解决什么

载流能力、温升这些性能，现在只能靠算、靠经验、靠做样品试。要训练一个模型，让工程师在设计阶段就能问：这个端子过 16 A，会热到多少度？

## 你负责的检查项

| ID | 名称 | 难度 | 期次 | 判定要点 |
|---|---|---|---|---|
| `PERF-01` | 载流-温升预测 | L3 | 一期 | 由几何/材料/工况特征预测稳态温升与允许载流，输出区间 |
| `PERF-02` | 插拔力预测 | L3 | 二期 | 由接触簧片几何/材料/过盈量预测插入力、拔出力 |

## 从哪开始

第一周只做选型，别急着写模型。样本量只有几百条，难点在数据不在算法。

## 三个命令

```powershell
python -m nxdrp checkers                                   # 确认自己被认出来了
python -m nxdrp check mockdata/models/board_a.model.json --only <你的ID>
python -m unittest discover -s tests
```

## 几个提醒

- 用 NX 参数化批量仿真造 ≥300 条样本——这是本项目最大的底牌，别浪费。
- 结果要给区间，不要只给一个数；模型卡写清适用什么范围、超出范围为什么不能用。

## 交之前自查

- [ ] 在 Mock 模型**和**至少一个真实 NX 模型上都跑出正确结果
- [ ] 每条结果带 `face_ids`，工程师能点回 3D 现场
- [ ] 建议能照着改（给目标尺寸或结构动作），不是「请注意检查」
- [ ] 阈值写在 `rules/` 里，代码里只有默认值
- [ ] 数据不够时跳过并说明缺什么，不产出假结果
- [ ] 正例 / 负例 / 边界三个测试都有
