# 选型说明：PERF-02 插拔力

**负责人**：杜滨芳　　**截止日期**：2026-10-29

## 背景

本项是 PERF-02 插拔力。另一项是 PERF-01 载流–温升，见 `选型说明.md`。  
本项有样本、模型、检查项和推理入口。

## 预测

| 指标 | 单位 | 判据 |
|---|---|---|
| 插入力 | N | 超过上限（默认 20 N）报 P2 |
| 拔出力 | N | 低于下限（默认 1 N）报 P3 |

另给 80% 区间。阈值在 `rules/dfm_default.json` 的 R-PERF-02。

## 数据来源

360 条。标签 = 悬臂梁摩擦公式 × 对数正态散差（标准差 0.08）。`label_source` = `cantilever_friction_v1`。

公式（`force_physics.py`）：

```
I    = b·t³ / 12
k    = 3EI / L³
Fn   = k·δ
Fin  = n·Fn·(μ + tanθ)/(1 − μ·tanθ)
Fout = n·Fn·μ
```

每个接触点按等截面悬臂簧片。过盈量 δ 由弯曲承担。θ、μ、n 取规则默认值。  
弹性模量：CuSn6 110 GPa、CuBe2 131 GPa、CuZn37 100 GPa。

## 几何

零件包围盒三条边：最短为厚度 t，中间为宽度 b，最长为长度 L。  
过盈量、摩擦系数、接触点数取规则默认值。  
Finding 的 `note` 写明尺寸来自包围盒。更换几何时替换 `spring_spec()`。

## 模型

回归树拟合「插入力 / 公式插入力」的对数。点预测 = 公式 × exp(修正)。深度最多 4，叶子至少 6 条。  
划分 240 / 60 / 60。数字见 `PERF02模型卡.md`。

## 范围

| 量 | 范围 |
|---|---|
| 簧片长度 | 6–15 mm |
| 簧片宽度 | 1–4 mm |
| 簧片厚度 | 0.2–0.6 mm |
| 过盈量 | 0.1–0.5 mm |
| 摩擦系数 | 0.12–0.30 |
| 材料 | CuSn6、CuBe2、CuZn37 |

超出范围时检查项跳过。

## 命令

```powershell
python -m nxdrp check nxdrp/checkers/m5_performance/data/contact_spring.model.json --only PERF-02
python -m nxdrp.checkers.m5_performance.predict_insertion --length-mm 8 --width-mm 2 --thickness-mm 0.5 --material CuSn6
```

`data/contact_spring.model.json`：手写样例，6×4×0.6 mm，材料 CuSn6。
