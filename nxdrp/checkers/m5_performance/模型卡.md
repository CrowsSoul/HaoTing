# PERF-01 模型卡：载流–温升

## 预测

输入：截面积、导体长度、材料电阻率、电流、对流换热系数。  
输出：稳态温升 ΔT（°C），置信度 80% 的区间，以及温升回到允许值以下的电流。

允许温升默认 45 °C，在 `rules/dfm_default.json` 的 `max_rise_c`。

## 数据来源

共 360 条，随机种子 20261029。

| 用途 | 条数 | 用途说明 |
|---|---|---|
| 训练 | 240 | 拟合回归树 |
| 标定 | 60 | 定区间分位数 |
| 测试 | 60 | 只报误差和覆盖率 |

温升由模拟 NX 仿真 `thermal_solver.simulate_nx_delta_t` 生成。  
在集总对流之外含辐射、电阻率随温度、端部接触电阻。

集总公式：

- 发热 P = I² ρ L / A
- 散热面积 = 侧面 π d L + 两端 2A
- ΔT = P / (h · 散热面积)

材料电阻率：Cu（ρ=1.724e-08 Ω·m）、CuSn6（ρ=1.300e-07 Ω·m）、CuZn37（ρ=6.200e-08 Ω·m）、CuBe2（ρ=7.800e-08 Ω·m）。纯铜为 1.724×10⁻⁸ Ω·m。  
替换 `delta_t_c` 后运行 `python -m nxdrp.checkers.m5_performance.train`。

## 模型

回归树拟合「样本温升 / 集总公式」的对数。  
点预测 = 集总公式 × exp(修正)。最大深度 4，叶节点至少 6 条。  
特征：截面积、长度、电阻率、电流、换热系数的对数。  
环境温度用于绝对温度和范围判断，不作为特征。

## 误差

测试集 60 条，未参与训练，未参与标定。

| 指标 | 数值 |
|---|---|
| 中位绝对误差 | 0.71 °C |
| 平均绝对误差 | 19.45 °C |
| 温升 1–200 °C 档中位绝对误差 | 0.83 °C |
| 80% 区间覆盖率 | 84.2% |

平均绝对误差含上千度样本。标定集分位数 q_low = 0.9408，q_high = 1.1561。  
自查线：1–200 °C 档中位绝对误差 ≤ 2.0 °C，覆盖率 ≥ 70%。  
本次：0.83 °C，覆盖率 84.2%。

## 范围

| 量 | 范围 |
|---|---|
| 截面积 | 0.5–20.0 mm² |
| 导体长度 | 5.0–40.0 mm |
| 电流 | 1.0–40.0 A |
| 环境温度 | 0.0–80.0 °C |
| 对流换热系数 | 8.0–25.0 W/(m²·K) |
| 材料 | Cu、CuSn6、CuZn37、CuBe2 |
| 区间置信度 | 0.8 |

截面积取半径最小的圆柱面，A = πr²，长度由该圆柱侧面面积反推。

## 范围外

电流、尺寸、材料、换热系数或置信度超出上表时，检查项跳过并写明缺项。  
无材料、绝缘材料（如 PA66）、无圆柱面时同样跳过。

## 局限

- 模拟 NX 含对流、辐射、电阻随温度和端部接触。不含壳体导热，不含网格。
- 0.5–2 mm² 的中位误差含高温点。分档见 `python -m nxdrp.checkers.m5_performance.evaluate`。
- 未参与训练的材料，覆盖率下降。
