# PERF-02 模型卡：插拔力

## 预测

输入：簧片长度、宽度、厚度、过盈量、弹性模量、摩擦系数、接触点数。  
输出：插入力、拔出力（N），置信度 80% 的区间。

插入力上限 20.0 N，拔出力下限 1.0 N，在 `rules/dfm_default.json` 的 R-PERF-02。

## 数据来源

共 360 条，随机种子 20261029。

| 用途 | 条数 | 用途说明 |
|---|---|---|
| 训练 | 240 | 拟合回归树 |
| 标定 | 60 | 定区间分位数 |
| 测试 | 60 | 只报误差和覆盖率 |

标签 = 悬臂梁摩擦公式 × 对数正态散差（标准差 0.08，截断 0.75–1.30）。`label_source` = `cantilever_friction_v1`。

- I = b t³ / 12
- k = 3 E I / L³
- Fn = k δ
- Fin = n · Fn · (μ + tanθ) / (1 − μ·tanθ)
- Fout = n · Fn · μ

弹性模量：CuSn6（E=110 GPa）、CuBe2（E=131 GPa）、CuZn37（E=100 GPa）。μ、θ、n 取规则默认值。材料表不含纯铜。  
替换 `insertion_n` / `withdrawal_n` 后运行 `python -m nxdrp.checkers.m5_performance.force_train`。

## 模型

回归树拟合「插入力 / 公式插入力」的对数。点预测 = 公式 × exp(修正)。  
最大深度 4，叶节点至少 6 条。  
特征：长度、宽度、厚度、过盈量、弹性模量、摩擦系数的对数。

## 误差

测试集 60 条。

| 指标 | 数值 |
|---|---|
| 中位绝对误差 | 0.125 N |
| 平均绝对误差 | 0.528 N |
| 插入力 1–100 N 档中位绝对误差 | 0.210 N |
| 80% 区间覆盖率 | 80.9% |

q_low = 0.9222，q_high = 1.1579。  
自查线：1–100 N 档中位绝对误差 ≤ 1.0 N，覆盖率 ≥ 70%。  
本次：0.210 N，覆盖率 80.9%。

## 范围

| 量 | 范围 |
|---|---|
| 簧片长度 | 6.0–15.0 mm |
| 簧片宽度 | 1.0–4.0 mm |
| 簧片厚度 | 0.2–0.6 mm |
| 过盈量 | 0.1–0.5 mm |
| 摩擦系数 | 0.12–0.3 |
| 材料 | CuSn6、CuBe2、CuZn37 |
| 区间置信度 | 0.8 |

## 范围外

尺寸、过盈量、摩擦系数或材料超出上表时，检查项跳过并写明缺项。

## 局限

- 悬臂梁、小变形、线弹性。不含塑性、接触非线性、二次插入。
- 摩擦系数为常数。
- 不含壳体导向、锁扣、密封圈、对插偏斜。
- 几何取自零件包围盒，最短边为厚度。
