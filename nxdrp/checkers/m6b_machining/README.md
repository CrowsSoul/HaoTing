# M6 机加工类 DFM（12 项）

**负责人**：张百瑞　　**目录**：`nxdrp/checkers/m6b_machining/`

## 这个模块在解决什么

孔太深钻头会断、圆角太小刀具进不去、孔径不在标准刀具系列还得定制刀。
这 12 项把「加工做不出来或者成本高」的地方标出来。

## 你负责的检查项

| ID | 名称 | 难度 | 期次 | 判定要点 |
|---|---|---|---|---|
| `DFM-27` | 深孔 | L1 | 一期 | 孔深/孔径 > 4（标准钻）或 > 10（深孔） |
| `DFM-28` | 深窄槽 | L1 | 一期 | 槽深/槽宽 > 3~4 |
| `DFM-29` | 平底盲孔 | L1 | 一期 | 盲孔底面为平面（无钻尖角），不利排屑 |
| `DFM-30` | 刀具可达性 | L3 | 二期 | 沿孔/槽轴线的刀具包络无遮挡 |
| `DFM-31` | 特征尺寸与刀具标准 | L1 | 一期 | 孔径/槽宽落在标准刀具系列（Φ1/2/3/4/5/6/8/10/12…）内 |
| `DFM-32` | 底部圆角一致性 | L1 | 一期 | 底面圆角半径种类数 > N（换刀次数过多） |
| `DFM-33` | 顶部圆角 | L1 | 一期 | 顶边 R < 刀具最小 R 或缺失 |
| `DFM-34` | 内部倒角 | L1 | 一期 | 内角倒角角度/尺寸不在标准范围 |
| `DFM-35` | 深圆角转角 | L2 | 二期 | 内腔转角 R < 刀具 R（刀具进不去） |
| `DFM-36` | 角度铣削面 | L1 | 一期 | 侧面与底面/基准面夹角非 90° 且非标准角 |
| `DFM-37` | 窄通道 | L3 | 二期 | 通道宽度 < 最小刀具直径 |
| `DFM-38` | 孔的入刀/出刀面 | L1 | 一期 | 孔入口/出口面法向与孔轴夹角 > 阈值 |

## 从哪开始

同样是一套读表执行的代码 + 12 行阈值。
DFM-31/32 已有完整示例，照着往下铺。

## 三个命令

```powershell
python -m nxdrp checkers                                   # 确认自己被认出来了
python -m nxdrp check mockdata/models/board_a.model.json --only <你的ID>
python -m unittest discover -s tests
```

## 几个提醒

- 标准刀具库放 `rules/tool_library.json`，不要写死在 checker 里。
- DFM-30 刀具可达性、DFM-37 窄通道要算空间遮挡，难度高一个量级，排二期。
